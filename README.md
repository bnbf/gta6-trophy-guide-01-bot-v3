Leonida Platinum — an offline GTA 6 trophy guide and tracker. All 55 official trophies with a guide to each in our own words, a checklist that saves in your browser (with export and import), search and filters by kind and grade, a spoiler setting that hides story trophies until earned, a 6-stage roadmap to the platinum, and the 7 missables flagged. Sources are Exophase (official list) and PSNProfiles (tracked counts).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network — the whole guide is static files under `app/`.
